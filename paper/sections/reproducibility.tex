\section*{Reproducibility}

{\sloppy
Everything is released: the finite-grid Bayesian aggregator, all neural
baselines, the smoke tests, and a brute-force unit test
(\texttt{code/test\_predictive\_fix.py}) that checks the
posterior-predictive log-odds against explicit enumeration. From the
repository root, \texttt{python code/smoke\_test.py} verifies the core
components in under ten seconds; \texttt{python code/run\_all\_n10.py}
reproduces every table and figure in the paper (ten seeds; a few hours on
a CPU-only machine). All randomness goes through a deterministic
\texttt{SafeRNG} wrapper around Python's \texttt{random.Random}; PyTorch
seeds are set before every model initialisation. The repository's
\texttt{REPRODUCIBILITY.md} documents the environment, the per-experiment
design, the baseline information budgets, and every correction applied
during independent reproduction---including the posterior-predictive fix
described in Section~\ref{sec:method}, which changed the estimator from a
posterior expectation of log-odds to the exact predictive quantity. For
double-blind review, the code and data are provided as anonymised
supplementary material; the camera-ready version will carry a persistent
DOI.
\par}
